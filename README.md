VICE COVER turns your photos and a caption into GTA 6-style poster cover art: multi-panel layouts (Vice Trio, Split Duo, Solo Hero, and a five-panel Cover Grid with one hero panel and four satellites), a sunset-gradient title with a double outline, a neon script tagline, and four colour grades (Sunset, Neon, Palm Gold, Noir) applied as true gradient maps with a light cel-shade posterize. Drop in any photos, drag to crop each panel, pick a post size (square, portrait or landscape), and export a share-ready PNG — one size, or all three sizes at once. Everything runs locally in the browser — your photos never leave your machine, and the app works fully offline with no network calls and no Rockstar artwork, logos or fonts.

Open `app/index.html` in a browser to use it.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only, no network) writes the submission dossier for the entry.
